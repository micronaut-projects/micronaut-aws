Since the list of services offered by AWS is huge, you can write your own client support and leverage the foundation
classes that support the services supported by Micronaut.

To do so, you would create a `@Factory` class that would get injected some other beans to do its job.

For example, to create a client for AWS Rekognition:

snippet::io.micronaut.docs.aws.sdk.v2.RekognitionClientFactory[tags="class"]

NOTE: A Python class cannot extend the Java class `AwsClientFactory`, so the Python factory configures the builders itself with the same injected beans (`AwsCredentialsProviderChain`, `AwsRegionProviderChain`, `UserAgentProvider` and the named `AWSServiceConfiguration`) the parent class uses.

<1> The builder is created and configured with the HTTP client, the region, the credentials and the endpoint override. You may apply

    customised.
<3> This method builds the client and exposes it as a `@Bean`.
