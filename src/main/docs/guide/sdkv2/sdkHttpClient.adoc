The AWS SDK v2 selects an HTTP client from the classpath. Since AWS SDK v2 `2.46.0` the sync
default is the Apache HttpClient 5.x based client (`software.amazon.awssdk:apache5-client`),
pulled in transitively by the service modules; Netty (`netty-nio-client`) is the async
default. Micronaut AWS configures whichever client is present, as described below.

Only one sync HTTP client may be on the classpath. The AWS SDK fails with a
`Multiple HTTP implementations were found on the classpath` error when more than one sync client
is present and no `software.amazon.awssdk.http.service.impl` system property is set. If you wish to
use a client based on the JVM's lightweight `URLConnection`, configure it as explained below.

NOTE: Micronaut AWS sets the `User-Agent` header for all clients as `micronaut/<version>`. If you don't want to include that HTTP Header, set `aws.ua.enabled` to `false` or https://docs.micronaut.io/latest/guide/#replaces[replace] the bean of type `io.micronaut.aws.ua.UserAgentProvider`.
